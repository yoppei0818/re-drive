# 08｜運用・安全・プライバシー方針

> [!WARNING]
> Re:Driveはルートの安全性を保証しません。道路状況、交通規制、天候、現地標識、運転者自身の判断を常に優先します。

## 安全UX

- 条件設定、比較、選択は必ず運転開始前に行う
- 運転中にRe:Driveの操作を要求しない
- 実際の案内はGoogle Mapsへ引き渡す
- アプリ内のプレビュー経路とGoogle Mapsで再計算される経路が異なる可能性を表示する
- 「安全ルート」ではなく「練習難易度」「走行上の特徴」と表現する
- 道路状況や交通状況は実際の状況を優先する旨を表示する
- Google Mapsへ移る前に、停車中であることを確認する
- Google Mapsへ移った後は、実際に表示された経路と交通状況を運転前に確認する

## AIガードレール

- AIに道路の存在や交通状況を推測させない
- Google Maps由来の特徴量だけを入力する
- 難易度は原則として決定論的ルールで算出する
- AIは説明とアドバイスを担当し、難易度スコアを上書きしない
- 「安全」「事故が起きない」などの保証表現を禁止する
- AIが失敗した場合は事実ベースのテンプレート説明を表示する

## プライバシー

- 位置情報を利用する目的を明示し、必要なときだけ取得する
- 生の位置履歴をMVPで常時収集しない
- データの保存期間と削除方法を定義する
- ログでは座標をマスクまたは丸める
- ユーザーが履歴とアカウントを削除できるようにする
- APIキーとサービスロール鍵をクライアントに配置しない

## セキュリティ

- 通信にはTLSを使用する
- FastAPIでSupabase JWTを検証する
- SupabaseでRLSと最小権限を適用する
- Secret managerで秘密鍵を管理する
- ユーザー単位のrate limitと濫用検知を導入する
- 依存関係と権限設定を定期的に点検する

## 外部規約と公開

- Google Maps Platformの利用規約、表示、帰属要件を確認する
- Navigation SDKを将来組み込む場合は、追加要件と同意導線を再確認する
- App Store / Google Playの審査とデータ取扱い申告に対応する
- 一般公開や課金の前に、利用規約、免責、プライバシーポリシーの専門家レビューを検討する
- 公開時点の法令、ストア審査基準、外部API規約を改めて確認する

## 運用監視

- Google API / AI APIの失敗率とレイテンシ
- ルート生成成功率と候補不足率
- 希望時間と推定時間の乖離
- ルート難易度とユーザーの任意評価の乖離
- 1ユーザーあたりのAPIコスト
- 安全上の報告と問い合わせ

## インシデント対応

1. 問題のあるルートや説明を記録する
2. 影響範囲とスコアリングバージョンを特定する
3. 必要に応じて機能停止またはルール変更を行う
4. ユーザーへ通知し、再発防止策を実施する

## 現時点の位置づけ

事前の安全認証を前提とする構想ではありません。ただし、実走を伴う検証や一般公開の前には、安全表示、データ取扱い、最新の法令と外部規約を別途レビューします。
