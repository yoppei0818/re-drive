# 01｜企画概要・プロダクト方針

## プロダクト概要

Re:Driveは、ペーパードライバーが久しぶりの運転を無理なく再開するための「運転練習ルート提案」アプリです。

現在地、練習時間、立ち寄りたい場所、避けたい条件をもとに、出発地点へ戻る周回型の練習ルート候補を提示します。各候補には所要時間、距離、練習難易度、評価理由、注意点を添えます。

## 解決したい課題

- 久しぶりに運転したいが、どこを走ればよいか分からない
- 一般的なナビは目的地への到達を最適化し、練習しやすさを考慮しない
- 高速道路、細い道、複雑な交差点などへの不安がある
- 自分にとって無理のない練習ルートを見つけにくい

## 提供価値

ユーザーが運転を開始する前に、自分の希望に近い練習ルートを比較し、ルートに含まれる操作の複雑さを理解したうえで選択できるようにします。

## MVPの核

**現在地 + 運転時間 + 避けたい道路 → 練習ルート3案**

## ポジショニング

| サービス | 主な目的 |
| --- | --- |
| Google Maps / カーナビ | 目的地へ効率よく到達する |
| 運転学習アプリ | 知識や操作を学ぶ |
| 試験ルートアプリ | 免許試験コースを練習する |
| Re:Drive | 本人に合った運転練習そのものを設計する |

## 想定ユーザー

- 免許取得後、長期間運転していない人
- 生活環境の変化で再び運転が必要になった人
- 教習所へ通う前後に自主練習したい人

## プロダクト原則

1. 運転前の意思決定を支援する
2. 実際の案内はGoogle Mapsへ委ねる
3. 「安全」を保証せず、練習難易度を推定・説明する
4. 地理的事実は地図API、評価は決定論的ルール、説明はAIに分担する
5. MVPでは機能を増やしすぎず、周回ルート提案の価値を検証する

## 将来像

- 累計運転時間、走行距離、運転回数の振り返り
- 日付、地図、ルート特徴を確認できる履歴詳細
- 駐車、右左折、幹線道路、夜道など目的別のルート条件
- 過去に選んだ条件や保存ルートの再利用
